# Adapt (article-normalizer)

Настольное приложение с графическим интерфейсом (PyQt5) для приведения названий и артикулов позиций в рабочих документах (сметах, спецификациях, ведомостях материалов) к единому эталонному виду.

Приложение помогает специалистам, работающим с большими Excel-таблицами оборудования и материалов, быстро находить для «сырых» наименований и артикулов их эталонные соответствия из базы данных, а также конвертировать таблицы из PDF в Excel перед обработкой.

## Возможности

- **Перевод PDF → Excel.** Извлечение табличных данных из PDF-файлов (с помощью `tabula-py`) и сохранение каждой таблицы на отдельный лист `.xlsx`.
- **Разметка колонок.** Перед обработкой пользователь указывает, какие колонки таблицы соответствуют артикулу, наименованию, количеству, единице измерения и до трёх дополнительных полей.
- **Поиск и предложение замен.** Для каждой строки таблицы алгоритм подбирает эталонное наименование/артикул на основе базы данных `standards.json`:
  - точное совпадение наименования и/или артикула с эталоном;
  - совпадение с ранее сохранёнными («не эталонными») названиями и артикулами;
  - нечёткий поиск похожих названий (`difflib.get_close_matches`).
  
  Каждому варианту присваивается «уровень уверенности» и он подсвечивается цветом (зелёный — точное совпадение, синий — вероятное, жёлтый — по схожести).
- **Проверка и нормализация единиц измерения** (шт., м, м², кг и их варианты написания).
- **Пополнение базы данных** — как вручную (через список эталонных названий), так и массово, загрузкой готового Excel-файла с эталонами.
- **Сохранение результата** обработки обратно в Excel, с возможностью объединения нескольких листов в один.

## Как это устроено

Общая схема работы приложения:

![Архитектура приложения](images/architecture.png)

Входной файл (PDF или Excel) обрабатывается декодировщиками, размечается пользователем через интерфейс разметки, затем алгоритм сопоставляет позиции с хранилищем эталонных данных (`standards.json`) и формирует выходной Excel-файл.

## Скриншоты

**Главное меню** — точка входа в приложение: загрузка базы данных, просмотр эталонных названий, конвертация PDF в xls и запуск обработки.

![Главное меню](images/main_menu.png)

**Разметка колонок** — сопоставление колонок загруженной таблицы с нужными полями (артикул, наименование, количество, единица измерения, доп. информация).

![Окно разметки](images/marker.png)

**Замена позиций** — основное рабочее окно: слева текущая таблица с уже найденными и подсвеченными совпадениями, справа — карточка выбранной строки и список предложенных эталонных вариантов с пояснением, почему они предложены.

![Окно замены](images/replacer.png)

**Список эталонных названий** — просмотр, редактирование и удаление эталонных позиций базы данных (наименование, артикул, единица измерения).

![Список эталонных названий](images/standards.png)

## Установка

Требуется Python 3.8+ и Java Runtime (JRE) — он нужен библиотеке `tabula-py` для чтения PDF.

```bash
git clone https://github.com/protuberancer/article-normalizer.git
cd article-normalizer
pip install PyQt5 pandas numpy tabula-py openpyxl
```

## Запуск

```bash
python app.py
```

## Основные файлы

| Файл | Назначение |
|---|---|
| `app.py` | Графический интерфейс приложения (PyQt5): главное меню, окна разметки, замены и работы со списком эталонных названий |
| `ExcelReplacer.py` | Логика сопоставления и поиска замен: работа с `standards.json`, проверка единиц измерения, нечёткий поиск похожих наименований |
| `PdfReader.py` | Извлечение таблиц из PDF и сохранение их в Excel (`tabula-py`) |
| `clear.py` | Вспомогательный скрипт очистки/подготовки данных |
| `standards.json` | База данных эталонных наименований, артикулов, единиц измерения и истории замен |

## Формат базы данных (`standards.json`)

Каждая запись базы — эталонное наименование, для которого хранятся:

```json
{
  "Эталонное наименование": {
    "standard_article": "Эталонный артикул",
    "measure": "шт",
    "names": ["ранее встречавшиеся варианты названия"],
    "articles": ["ранее встречавшиеся варианты артикула"]
  }
}
```
